# Menarguez-IA SOC Lab

Laboratorio práctico de **Security Operations Center (SOC)** orientado a **Blue Team**, diseñado para simular un entorno empresarial real y entrenar tareas de **SOC L1 / L2**.

El laboratorio simula la infraestructura de la empresa **Menarguez-IA**, integrando:
- SIEM (Wazuh)
- Endpoints Linux
- Servicios web simulados
- Generación de eventos reales
- Casos de uso alineados con MITRE ATT&CK

---

## 🎯 Objetivos del laboratorio
- Simular un SOC realista basado en herramientas open-source
- Practicar detección, análisis y respuesta a incidentes
- Generar experiencia práctica demostrable en GitHub
- Servir como base para ampliaciones (Blue Team, IA, automatización)

---

## 🧱 Arquitectura (alto nivel)

- **Wazuh SIEM** (Manager + Indexer + Dashboard)
- **Endpoints Linux** (Wazuh Agent)
- **Servicios simulados** (Web, SSH, sistema)
- **Scripts de generación de eventos**
- **Casos SOC documentados**
